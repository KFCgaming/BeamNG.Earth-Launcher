# BeamNG.Earth Launcher  [![BeamNG.Earth](https://img.shields.io/badge/BeamNG.Earth-GitHub-41454A?style=for-the-badge&logo=github&logoColor=orange)](https://github.com/TecnaGamer/BeamNG.Earth)
### An Auto-Update Launcher for the BeamNG.Earth mod by TecnaGamer 📥

I created this launcher **to automate updates for the BeamNG.Earth mod**.
**It works very simply: just launch it**. The program will compare the version of the mod you currently have installed with the latest version available on the official GitHub repository and will replace it if an update is found.

**The launcher only works on Windows** ⚠️ (I will try to add support for other operating systems over time). However, I am also **providing the Python file** for the launcher, which depends on the following packages: **requests, colorama**.

You can download the latest version in the <a href="https://github.com/KFCgaming/BeamNG.Earth-Launcher/releases">Releases tab</a>.
